## Atividade Grunt EBAC
Nesta atividade foi utilizado Grunt para o desenvolvimento Front-end juntamente do NodeJS para a criação de uma web pizzaria, apenas o Front-end esta funcionando, enquanto que o back-end
não foi desenvolvido. Possui responsividade mobile e tablet.
